# n8n Cybersecurity Workflows

Zanonimizowane przykłady workflow n8n związane z administracją, monitoringiem i bezpieczeństwem.

Eksporty nie zawierają poświadczeń, rzeczywistych webhooków ani publicznych adresów administracyjnych. Po imporcie wymagają ręcznej konfiguracji credentials i endpointów.

## Przykłady
- `security-alert-triage.json` — przyjęcie przykładowego alertu, normalizacja i ocena priorytetu.
- `daily-cyber-briefing.json` — szkielet dziennego briefingu cyber/IT.

## Bezpieczeństwo
Nie commituj credentials, tokenów API, kluczy webhook, kluczy LLM, adresów paneli administracyjnych ani pełnych logów z danymi osobowymi.
